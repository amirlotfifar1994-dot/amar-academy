# انتقال آمارآموز به کامپیوتر دیگر

کد، محتوای آموزشی، تصاویر، قلم، آزمون‌ها، فایل قفل وابستگی‌ها و خروجی آمادهٔ `dist` در همین مخزن قرار دارند. اجرای برنامه به Codex، حساب OpenAI، کلید API یا سرویس پشتیبان نیاز ندارد.

## دریافت پروژه

مخزن: https://github.com/amirlotfifar1994-dot/amar-academy

در سیستم مقصد:

```sh
git clone https://github.com/amirlotfifar1994-dot/amar-academy.git
cd amar-academy
```

بدون Git نیز از **Code → Download ZIP** استفاده و فایل را استخراج کنید. پوشهٔ شامل `package.json` و `Run-App.cmd` ریشهٔ پروژه است. برای دریافت به‌روزرسانی‌های بعدی در نسخهٔ cloneشده، از `git pull` استفاده کنید؛ ابتدا تغییرهای محلی خودتان را ذخیره کنید.

## فقط دیدن نسخهٔ آماده

این روش به نصب وابستگی‌های React و اتصال اینترنت هنگام اجرا نیاز ندارد؛ Python 3 باید روی سیستم مقصد نصب باشد.

- ویندوز: فایل `Run-App.cmd` را اجرا کنید. این فایل از Python نصب‌شده روی همان سیستم استفاده می‌کند.
- macOS یا Linux: در پوشهٔ پروژه این دستور را اجرا کنید:

```sh
python3 -m http.server 5180 --bind 127.0.0.1 --directory dist
```

سپس `http://127.0.0.1:5180/` را در مرورگر باز کنید. پنجرهٔ سرور را باز نگه دارید؛ با Ctrl+C متوقف می‌شود. فایل `dist/index.html` را مستقیماً با دوبار کلیک باز نکنید؛ بارگذاری فایل‌های برنامه به سرور محلی نیاز دارد. اگر پورت اشغال است، سرور قبلی را ببندید یا در دستور دستی پورت دیگری مثل 5181 بگذارید و نشانی مرورگر را هم عوض کنید.

## توسعه، آزمون و ساخت دوباره

Node.js نسخهٔ 24 برای این پروژه انتخاب شده است؛ حداقل مورد نیاز تنظیمات فعلی 22.13 است. ابزار بسته‌ها `pnpm` با نسخهٔ دقیقِ ثبت‌شده در `package.json` است. برای نصب اولیهٔ ابزار می‌توانید از npm همراه Node.js استفاده کنید:

```sh
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm dev
```

پیش‌نمایش توسعه در `http://127.0.0.1:5173/` باز می‌شود. برای بررسی و ساخت:

```sh
pnpm test
pnpm build
pnpm preview
```

خروجی آماده در `dist` ساخته و پیش‌نمایش آن در `http://127.0.0.1:5180/` ارائه می‌شود. نصب اولیهٔ وابستگی‌ها به اینترنت نیاز دارد. پوشهٔ `node_modules` را از سیستم قبلی کپی نکنید؛ `pnpm install --frozen-lockfile` وابستگی‌های مناسب سیستم مقصد را از روی `pnpm-lock.yaml` نصب می‌کند.

برای GitHub Pages مخزن فعلی:

```sh
pnpm build:pages
```

این دستور خروجی جداگانه‌ای در `.pages-dist` با پیشوند `/amar-academy/` می‌سازد. این خروجی برای مسیر مخزن روی GitHub Pages است؛ برای اجرای محلی معمولی از `dist` استفاده کنید. نام مخزن یا مسیر میزبانی اگر تغییر کند، گزینهٔ `--base` باید مطابق آن تغییر کند. شاخهٔ `gh-pages` خروجی سایت عمومی را نگه می‌دارد؛ کد قابل توسعه در شاخهٔ `main` است.

## فایل‌های مهم

| مسیر | محتوا |
| --- | --- |
| `src` | رابط و محاسبات آموزشی، مقاله‌ها و آزمون‌ها |
| `public/course.json` | محتوای اصلی مرجع |
| `public/downloads` | اسناد و فایل‌های آموزشی اصلی، از جمله بستهٔ نسخهٔ ۱۳ |

| `docs` | مستندات توسعه و پرامپت‌های تصاویر |
| `dist` | نسخهٔ ساخته‌شده برای اجرای آماده |
| `pnpm-lock.yaml` | نسخه‌های دقیق وابستگی‌ها |
| `.github/workflows/ci.yml` | بررسی نصب، آزمون و ساخت روی Linux در GitHub |

## انتقال پیشرفت و یادداشت‌های شخصی

کپی پروژه یا clone کردن، اطلاعات مرورگر قبلی را منتقل نمی‌کند. در دستگاه قبلی، صفحهٔ اصلی سایت را باز کنید و از **مرورهای من و پشتیبان یادداشت‌ها → پشتیبان و انتقال پیشرفت → دریافت پشتیبان فعلی** فایل JSON بگیرید. در دستگاه مقصد همان بخش را باز کنید، **انتخاب فایل پشتیبان** را بزنید و پس از بررسی پیش‌نمایش، انتقال را اعمال کنید.

این پشتیبان برای اطلاعات یادگیریِ تحت پوشش پنل است؛ داده‌های موقت آزمایشگاه و سناریوهای تعاملی جزو آن نیستند. هر گزارش یا فایل جداگانه‌ای را که نیاز دارید، جدا دریافت کنید. پشتیبان شخصی را در مخزن عمومی بارگذاری نکنید. تغییر مرورگر، نشانی یا پورت می‌تواند فضای ذخیره‌سازی جدا بسازد؛ از فایل پشتیبان برای انتقال استفاده کنید.
